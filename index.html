Is it safe?

Yes. Here is
how to check.

Windows may say Windows protected your PC. That is not a virus warning. Windows shows it for every new program that is not code-signed yet. A signing certificate costs money, so a new indie game usually does not have one yet. Signing will come before the full release.

Start the game

  1. Ask for the alpha with the form below. I share a Google Drive folder with you; download the zip from it. Drive says it cannot scan this file because the file is big: that is normal. If your browser says the file is not commonly downloaded, choose Keep. New files get that note until many people have them.
  2. Right-click the zip, then click Extract All.
  3. Open the folder and run DroneFight.exe.
  4. If the blue Windows box shows, click More info, then Run anyway.

What the game does
  • No installer. No admin rights needed. To remove it, delete the folder.
  • Keeps to its folder. Settings, logs and saved bug reports go into the game's own Saved folder.
  • Goes online only to check for updates (this website), play online matches (Steam), and send a bug report when you press SEND.
  • Big download, normal reason. It is an Unreal Engine 5 game. Most of the size is the engine and the art.

Gamepad not working?

This test build runs in Steam as "Spacewar", and Steam takes over the controller. Turn that off once:

  1. Open Steam and go to Library.
  2. Right-click Spacewar and choose Properties.
  3. Open Controller and pick Disable Steam Input.
